> 이 도구가 **어떻게 만들어지고 배포되는지**를 한 장에 정리하는 개발자용 문서입니다.
> 개별 기능 명세는 [위키](/wiki), 회고는 [개발노트](/devnote)에 씁니다.

## 한눈에 보는 구조

```
[사용자 PC]
   └─ 실행파일 (예: PyInstaller로 묶은 단일 .exe)
        └─ 핵심 로직 실행   ※ 필요 시 로컬/네트워크 동작 표시

[GitHub]
   └─ Releases (또는 dist 폴더)  ← 빌드 산출물 배포 채널

[Cloudflare Pages]  (이 사이트)
   └─ 소개(랜딩) · 릴리즈노트 · 위키 · 아키텍처 · 개발노트
        └─ "내려받기" 버튼이 위 배포 채널로 연결됨
```

## 구성 요소

| 레이어 | 무엇 | 왜 |
|---|---|---|
| **앱 본체** | (언어/프레임워크) | (선택 이유) |
| **패키징** | (예: PyInstaller → 단일 exe) | 사용자가 런타임 설치 없이 실행 |
| **배포** | GitHub Releases 또는 dist | 버전별 바이너리 보관 + 다운로드 링크 |
| **소개/문서** | 이 Astro 정적 사이트 | 실행파일에 담기 어려운 설명·문서·회고를 웹으로 |
